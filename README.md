# 日本株・米国株の日刊レポート（GitHub Actions + GitHub Pages）

This project generates daily Japanese and U.S. stock reports, stores them as Markdown and HTML files, and publishes them through GitHub Pages.

🌐 **公開サイト（GitHub Pages）：[株式NEWSを開く](https://gongonticktack.github.io/stock_daily_reports/)**

毎朝 **日本時間7:00頃**、日本株と米国株の日報を生成し、`reports/YYYY-MM-DD.md` と `docs/reports/YYYY-MM-DD.html` に保存します。GitHub Pagesで日付別に閲覧できるようにします。
